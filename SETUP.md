# Instalación rápida

1. En GitHub crea un repositorio PÚBLICO llamado exactamente:

   FrankDeveloperxd

2. Sube todo el contenido de esta carpeta al repositorio.

3. Confirma que README.md esté en la raíz.

4. Ve a:
   Actions -> Generate contribution snake -> Run workflow

5. Espera a que termine correctamente.

6. Vuelve a tu perfil de GitHub. El README aparecerá automáticamente.

FrankDeveloperxd/

## Qué reemplazar después

- Cambia los SVG de assets/projects por screenshots o GIFs de tus sistemas.
- Puedes mantener exactamente los mismos nombres de archivo.
- Revisa las descripciones de los proyectos en README.md.
- Si un proyecto tiene repositorio público, envuelve su imagen/título en un enlace.
